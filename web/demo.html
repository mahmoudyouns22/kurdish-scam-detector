How it decides

A scammer controls the spelling and the link. The pipeline handles both before the model sees a word.

1 · Normalise

Sorani and Arabic share a script but not its rules. Kurdish ی (U+06CC) and Arabic ي (U+064A) look identical and are different characters. Zero-width joiners, tatweel padding and Arabic-Indic digits all split a keyword invisibly. All of it is folded first.

2 · Fold entities

URLs, Iraqi phone numbers and amounts become __url__, __phone__, __money__. That a link exists is signal; memorising one scammer's domain is not learning.

3 · Character n-grams

2–5 character TF-IDF, not words. Kurdish is morphologically rich, spelling is inconsistent and the corpus is small — sub-word features degrade where word features fail outright.

4 · Named signals

28 hand-built features read the raw text, which still has the real domain. The sharpest: a genuine OTP gives you a code and says don't share it; a scam asks you to send one back.

5 · Linear model

Logistic regression, deliberately. Its coefficients are the explanation — every reason above is weight × value, the model's actual arithmetic, not a story told afterwards.

6 · Ship it

14,352 dimensions, 719 KB of JSON. The whole classifier ported to JavaScript and verified against the Python pipeline on all 3,321 rows — max difference 2×10⁻¹⁵.

Grouped on concept, not seed: the two seed files are parallel translations, so grouping naively puts the Arabic twin of a Kurdish test message into training. That bug inflated one row to 0.997 before it was caught. With signals disabled, transfer falls to 0.716–0.834 while in-language holds at 0.919–1.000 — so character n-grams over a shared script carry real but partial transfer, and the language-independent signal layer closes the rest. For a language with no scam corpus, that is the useful finding: you can bootstrap Kurdish detection from Arabic before collecting a single Kurdish message.

What it gets wrong

Stated here rather than left to be discovered. A reader who finds an unlisted weakness stops trusting everything else on the page.

  1. The entire corpus is synthetic. All 3,321 rows are authored — not one is a real intercepted message. Every number above measures whether authored scam patterns separate from authored legitimate ones. That is pattern separability, not field performance.
  2. The effective sample is 208, not 3,321. 208 hand-written seeds expanded ~16× by a template generator. Group-aware splitting keeps the test honest, but 42 held-out seeds per fold is small.
  3. Latin transliteration defeats it. F1 collapses to 0.483, recall to 0.318. A scammer writing Sorani in Latin script evades this today.
  4. Heavy obfuscation makes it cry wolf. A 25.3% false-positive rate under combined evasion. A tool that flags everything is useless.
  5. The Kurdish seeds await native-speaker review. Each seed is amplified ~16×, so a wrong register propagates to ~832 rows.
  6. Normalisation shows no in-distribution gain. It earns its place under orthographic shift (−1.8 points with it, −7.8 without), not on the headline number.
