3b. NORMALISATION UNDER ORTHOGRAPHIC SHIFT
==========================================================================
The i.i.d. ablation shows normalisation doing nothing, and that is
expected: train and test are perturbed by the same generator, so
the model simply memorises both spellings. Normalisation earns its
place when test-time orthography differs from training-time, which
is what this measures -- train on the normal training set, test on
a test set pushed into script variants the model has not seen.

with normalisation       clean F1 0.920   shifted F1 0.902   delta -0.018
without normalisation    clean F1 0.927   shifted F1 0.849   delta -0.078

4. ADVERSARIAL PROBE
==========================================================================
Evasions are applied to the WHOLE held-out set, both classes.
Scoring only evaded scam messages is misleading: mangling text
shreds it into rare n-grams that look nothing like clean ham, so
the model drifts toward 'scam' and recall appears to *improve*
while precision quietly collapses. The false-positive rate on
evaded ham is the column that exposes that.
These transforms never appear in training.
